# Demo

## 快速使用

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

開啟 http://localhost:5100

## 體驗流程

1. 選車：每台車的車況分數與車內整潔分級，點分數看車損明細
2. 車輛資訊：車況、整潔、停車位置、費率（COROLLA CROSS 同站租還專案價，來源 iRent 費率表，至 2026/11/30）
3. 用車頁：取車倒數 30:00、停車位置
4. 取車檢查：對照帳本 → 一致可略過（紀錄外新車損由本次承租人負責）／不一致拍四角＋標記位置拍特寫。
   回報的車損先標「待驗證」：AI 比對上次還車照片，高信心直接確認，中低信心進後台由人工判定屬實／駁回
5. 確認取車：安心服務可自選
6. 用車中 → 還車提醒 → 還車地點 → 先拍車內再拍車外（AI 即時檢查）→ 結果
7. 幫下一位找車：預設 AI 辨識柱號，辨識不到或有誤才手動填

右邊「模擬」分頁可切換情境（偏暗、模糊、拍錯車、舊照…）、模擬新刮傷、模擬柱號辨識失敗；「後台」分頁信心度 ≥ 0.90 自動結案，其餘依急迫性人工審。完成頁「重新開始」可重來。

## 注

- 真的在瀏覽器內計算：亮度、拉普拉斯清晰度、角落遮擋、dHash 防重複、硬性／軟性規則、車身覆蓋率、疊圖對位
- 示意：柱號辨識結果（示範圖取自借車照片中的 A02 柱子）、車牌 OCR 結果、車損偵測框與信心度、帳本歷史紀錄、後台佇列其他案件、營運看板數字、AI 客服回覆
